# Iowa Tequila Sales SQL Analysis

This project analyzes tequila sales from the Iowa Liquor Sales database using SQL and Excel.  
The goal of the project was to explore business performance, sales trends, vendor competition, and growth opportunities in the tequila market.

## Tools Used
- SQL
- PostgreSQL
- Excel
- PowerPoint

## Project Focus
The analysis focused on:
- Total tequila revenue
- High-performing and low-performing stores
- Revenue distribution across counties
- Vendor competition and market share
- Business strengths, weaknesses, opportunities, and threats (SWOT analysis)

## Key Findings
- Tequila generated over $21 million in revenue.
- Some stores and counties performed significantly better than others.
- Revenue was concentrated in a small number of stores and vendors.
- Large vendors dominated the tequila market, creating strong competition.

## Outcome
This project helped transform raw sales data into meaningful business insights using SQL queries, charts, and data visualization.
